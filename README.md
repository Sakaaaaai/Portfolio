# ポートフォリオウェブサイト

## 概要

このポートフォリオサイトは、「Life is what you make it」というテーマのもと、
自分のこれまでの経験や制作物を理解してもらうために作成しました。
自分の好きな色である緑をテーマカラーに採用しています。

## 特徴

- 様々な画面サイズに対応したレスポンシブデザイン
- Framer Motionを使用したインタラクティブなアニメーション
- 教育、フロントエンド開発、研究の経験を示すキャリアタイムライン
- インタラクティブなスキルカードを含むスキルセクション
- 詳細なプロジェクト情報を含む制作物ショーケース
- Typeformによるコンタクトフォームの統合

## 使用技術

- React.js
- Next.js
- TypeScript
- Tailwind CSS
- FirebaseYY

## プロジェクト構造

- `Hero.js`: ランディングページコンポーネント
- `Header.js`: ナビゲーションコンポーネント
- `CareerTimeline.tsx`: キャリアの進展を表示
- `Skills.js`: プログラミングスキルを紹介
- `Production.js`: 完成したプロジェクトをハイライト
- `Contact.js`: ユーザーの問い合わせ用Typeformを統合
